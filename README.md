## Project 1 - Mini Social Media App

The **Mini Social Media App** is a full-featured social platform where users can register, log in, customize user profiles, create micro-posts, like/unlike posts with live AJAX counters, leave comments, and follow/unfollow creators in real time.

- 📖 [Project Documentation](./codealpha-social-media-app/README.md)

### Features
- **Authentication**: User Registration, Login, Logout with Django Auth.
- **User Profiles**: Custom bio, location, auto-generated avatars, post counters, and follower/following stats.
- **Posts & Comments**: Create text posts and comment dynamically using AJAX.
- **Like & Follow System**: Interactive heart likes and user follow/unfollow toggles.
- **Glassmorphism UI**: Premium dark theme (`#0f172a`), Inter typography, responsive layouts, and floating toasts.

## Project 2 - Full Stack E-commerce Website

The **Full Stack E-commerce Website** is a comprehensive online store built with Django. It features a complete shopping experience with product listings, a dynamic shopping cart, a secure checkout process, and user order history.

- 📖 [Project Documentation](./full%20stack%20website/README.md)

### Features
- **Product Catalog**: Browse products with categories, search, and detail views.
- **Shopping Cart**: Add, update, and remove items dynamically.
- **Checkout & Payments**: Secure checkout flow integrated with Stripe.
- **User Accounts**: Registration, login, and order history tracking.
- **Modern UI**: Clean and responsive design using custom CSS and modern aesthetic principles.

- **Python 3.13** & **Django 6.0** - Backend Framework
